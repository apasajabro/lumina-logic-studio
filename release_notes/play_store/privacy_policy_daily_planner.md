# Privacy Policy for Daily Planner

Effective Date: 2026-06-29

Daily Planner is developed and published by Lumina Logic Studio.

This Privacy Policy explains how Daily Planner handles user data.

## Overview

Daily Planner is an offline daily planning app. The app allows users to create and manage tasks, descriptions, due dates, categories, priorities, and completion status.

Daily Planner is designed to work without login, cloud sync, advertising SDKs, analytics SDKs, Firebase, or backend servers.

## Data Collection

Daily Planner does not collect personal data from users.

The app does not transmit planner data to Lumina Logic Studio or to any third-party server.

## Local Data Storage

Planner data created inside the app is stored locally on the user's device using an offline database.

This may include:

1. Task title
2. Task description
3. Due date
4. Category
5. Priority
6. Completion status
7. Created date
8. Updated date

This information remains on the user's device.

## Data Sharing

Daily Planner does not sell, rent, or share user planner data with third parties.

## Login and Account

Daily Planner does not require account registration or login.

## Advertising and Analytics

Daily Planner does not use advertising SDKs or analytics SDKs.

## Permissions

Daily Planner does not request sensitive permissions such as:

1. Location
2. Camera
3. Microphone
4. Contacts
5. Broad file storage access

## Data Deletion

Users can delete tasks directly inside the app.

Users can also remove all local app data by uninstalling the app or clearing the app data from their device settings.

## Children's Privacy

Daily Planner is a general productivity app and does not knowingly collect data from children.

## Changes to This Privacy Policy

Lumina Logic Studio may update this Privacy Policy when necessary. Any updates will be posted on this page.
