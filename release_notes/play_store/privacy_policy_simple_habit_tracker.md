# Privacy Policy for Simple Habit Tracker

Effective Date: July 1, 2026

Simple Habit Tracker is developed and published by Lumina Logic Studio.

This Privacy Policy explains how Simple Habit Tracker handles user data.

## Overview

Simple Habit Tracker is an offline habit tracking app. The app allows users to create habits, add descriptions, choose categories, set frequency, set daily targets, mark habits as completed for the day, archive habits, restore habits, delete habits, and view simple local progress statistics.

Simple Habit Tracker is designed to work without login, cloud sync, advertising SDKs, analytics SDKs, Firebase, or backend servers.

## Data Collection

Simple Habit Tracker does not collect personal data from users.

The app does not transmit habit data to Lumina Logic Studio or to any third-party server.

## Local Data Storage

Habit data created inside the app is stored locally on the user's device using an offline database.

This may include:

1. Habit name
2. Habit description
3. Habit category
4. Habit frequency
5. Daily target
6. Habit color preference
7. Daily completion progress
8. Archive status
9. Created date
10. Updated date

This information remains on the user's device.

## Data Sharing

Simple Habit Tracker does not sell, rent, trade, or share user habit data with third parties.

## Login and Account

Simple Habit Tracker does not require account registration or login.

## Advertising and Analytics

Simple Habit Tracker does not use advertising SDKs.

Simple Habit Tracker does not use analytics SDKs.

Simple Habit Tracker does not display ads.

## Purchases and Payments

Simple Habit Tracker does not include in-app purchases, subscriptions, or payment features.

## Cloud Sync and Backend Servers

Simple Habit Tracker does not use cloud sync or backend servers.

Habit data is not uploaded to Lumina Logic Studio.

## Permissions

Simple Habit Tracker does not request sensitive permissions such as:

1. Location
2. Camera
3. Microphone
4. Contacts
5. Calendar
6. Photos or media library
7. Broad file storage access

## Data Deletion

Users can manage habit data directly inside the app.

Users can delete habits directly inside the app. When a habit is deleted, the habit and its local progress records are removed from the app database on the user's device.

Users can also remove local app data by uninstalling the app or clearing the app data from their device settings.

Because Simple Habit Tracker does not collect or store user data on Lumina Logic Studio servers, there is no server-side account data to delete.

## Children's Privacy

Simple Habit Tracker is a general productivity and habit tracking app and does not knowingly collect personal data from children.
